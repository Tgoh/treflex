# treflex-react

The React bindings for [treflex](../core/README.md): `TreflexProvider`, features, and the hooks a view reads the runtime through.

```
npm install treflex treflex-react solid-js react
```

The runtime runs on Solid's reactivity, so `solid-js` is installed alongside React. The [views reference](../../docs/reference/views.md#react) covers the React bindings.
